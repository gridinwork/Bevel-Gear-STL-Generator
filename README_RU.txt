Bevel Gear STL Generator

Генератор конических шестерён для Windows с 3D-предпросмотром и экспортом STL.

Быстрый запуск:
1. Установите Python 3.11 или новее.
2. Запустите install.bat.
3. Запустите start.bat.

Сборка EXE:
- запустите build_exe.bat;
- результат появится в dist\BevelGearGenerator\.

Основные функции:
- параметрическая генерация конической шестерни;
- число зубьев, диаметр и высота;
- центральное отверстие и шпоночный паз;
- угол давления;
- детализация сетки;
- 3D-предпросмотр на PyVista/VTK;
- экспорт STL.
